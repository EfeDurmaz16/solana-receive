# Security Policy

This repository is a custom-program reference implementation, not a mainnet
product or canonical Token-2022 deployment.

## Scope

Security reports should be limited to this repository's on-chain program,
client code, generated interfaces, scripts, and documentation that affect their
safe use.

## Reporting

Please report vulnerabilities through GitHub private vulnerability reporting if
it is available for this repository. If not, contact the maintainer through the
contact information on the GitHub repository or owner profile.

Do not disclose a suspected vulnerability publicly until it has been triaged.
No bug bounty or reward is promised.
